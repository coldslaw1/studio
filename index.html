The engines

Each engine is one folder of plain ES modules that a game copies in. They share a few rules: time is passed in, randomness is seeded, logic runs without a browser so it can be tested.

About this site

A static snapshot. Nothing here talks to a server.

Multiplayer is not playable here. Parley, the multiplayer engine, needs a small relay server, and this site is only static files. Its two example games, a tag game and a stone-placing board game, are left out.
The 3D text scenes are rendered ahead of time. Kiln builds each scene with the open-source Asciicker renderer, then the browser lights it, sorts characters behind scenery using the renderer's depth, and draws the live characters on top. The site carries the finished scenes, so it needs no native program.
